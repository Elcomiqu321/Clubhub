# Clubhub

Clubhub is a web app copy of the SportEasy team management app. It helps sports teams and clubs organize themselves in one place.

## Planned features

- **Rosters**: manage team members, roles and contact details.
- **Events**: schedule matches, trainings and other team events.
- **Availability**: let players say whether they can attend each event.
- **Chat**: talk with the team in group and private conversations.

This project is just getting started. No code has been added yet.
